# Daily Workout

Daily Workout publishes and tracks training programs. Built to Move is its
personal-first program for developing movement skill, useful strength,
flexibility, and long-term physical capacity.

## Language

**Built to Move cycle**:
A complete twelve-week run of Built to Move. A cycle keeps the longevity
standard while selecting a limited gymnastics and flexibility focus.
_Avoid_: Block, season, CAPABLE cycle

**Longevity standard**:
The programming rule applied throughout every Built to Move cycle: preserve
usable range, full-body strength, balance and control, and regular loaded or
weight-bearing movement. Aerobic work can supplement the three formal workouts
but is not the identity of Conditioning.
_Avoid_: Longevity workout, anti-aging guarantee

**Cycle focus**:
The limited outcomes emphasized for one Built to Move cycle. Cycle 1 focuses on
handstand and HSPU, pull-up and bar muscle-up, and pancake and overhead range.
General movement and flexibility remain part of the longevity standard.
_Avoid_: Level goal, permanent program identity

**Level**:
One four-week progression within a Built to Move cycle. Each level contains one
Lower, one Upper, and one Conditioning workout definition.
_Avoid_: Phase, month, block

**Workout definition**:
A reusable training prescription within a level. Built to Move has three
workout definitions per level and nine in a complete cycle.
_Avoid_: Daily post, session, workout template

**Workout emphasis**:
Lower, Upper, and Conditioning name the primary emphasis of a workout
definition. They are not isolated body parts or qualities. Supporting work
provides a second weekly exposure to movement patterns emphasized elsewhere.
_Avoid_: Body-part split

**Movement pattern**:
A basic action used to check that a cycle develops the whole body. Built to
Move uses vertical push, horizontal push, vertical pull, horizontal pull,
squat, hinge, one-leg work, trunk control, carry, locomotion, and optional
impact or landing.
_Avoid_: Muscle group, workout title

**Conditioning workout**:
The full-body workout definition that develops repeatable work capacity,
carries, locomotion, and loaded movement at controlled effort. It is not a race
or cardio-only training.
_Avoid_: Metcon, cardio day, CrossFit workout

**Supplemental aerobic work**:
Optional easy running, cycling, walking, or occasional higher-intensity
intervals performed outside the three formal workouts. It does not count toward
cycle completion.
_Avoid_: Conditioning workout, required session

**Session**:
One performance of a workout definition during a particular cycle week. Each
session is recorded independently even when the same workout definition is
repeated.
_Avoid_: Workout definition, workout template

**Weekly prescription**:
The exact sets, repetitions, holds, load guidance, assistance, and range shown
for one session occurrence. One workout definition owns four weekly
prescriptions.
_Avoid_: Exposure table, separate workout

**Progression**:
The deliberate change in one variable between sessions: load, volume,
assistance, range, hold duration, or movement difficulty.
_Avoid_: New workout, random variation

**Progression ladder**:
The ordered variations for a technical movement. A trainee uses the most
advanced variation that meets the stated quality check and can move up or down
independently of the current level.
_Avoid_: Beginner track, intermediate track, advanced track

**Quality check**:
The movement standard required before using a harder progression step. A
quality check selects the next variation; it does not determine cycle
completion.
_Avoid_: Test that must be passed, calendar progression

**Level rhythm**:
The four sessions of a workout definition within a level: establish, add
volume, add load or range, then consolidate and record. Week 4 is not an
automatic deload.
_Avoid_: Four different workouts, mandatory deload week

**Level completion**:
Four completed sessions of each workout emphasis. Completion advances the
cycle without requiring a final skill. Quality checks select the next movement
variation.
_Avoid_: Calendar month, pass/fail gate

**Loaded strength support**:
A stable kettlebell, dumbbell, or weighted bodyweight movement that supports
useful strength and measurable progress without defining the cycle. Cycle 1
uses double-kettlebell front squat, single-leg Romanian deadlift,
rear-foot-elevated split squat, kettlebell swing, and weighted pull-up.
_Avoid_: Barbell program, one-repetition-maximum program

**Pull-up**:
The overhand-grip vertical pull used as Cycle 1's main upper-body strength
thread. Bodyweight and weighted versions belong to the same progression.
_Avoid_: Chin-up

**Program run**:
One person's self-paced attempt through a Built to Move cycle. A new run
preserves the history of every earlier run.
_Avoid_: Program, cycle

**Session record**:
The progression-relevant results from one session occurrence within a program
run. Repeating a workout definition creates a new session record rather than
overwriting the earlier result.
_Avoid_: Workout record, workout-definition record

**Hinge**:
A lower-body movement pattern driven primarily from the hips. Romanian
deadlifts and kettlebell swings are hinge exercises.
_Avoid_: A synonym for conventional deadlift

**Skill practice**:
Optional low-fatigue practice outside the three formal workouts. It supports a
cycle focus but is never required for completion.
_Avoid_: Workout, mandatory session

**Archived program**:
A private earlier program retained only when deleting it would remove program
runs or session records. It is not shown as the current Training program.
_Avoid_: Active program, Built to Move
