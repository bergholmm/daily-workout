# Model session records as unrestricted workout history

MILE reuses workout definitions, and a user may perform the same workout any
number of times without selecting a program run or week. Each session record
therefore has its own identity and performed date and belongs to one user and
one workout definition. This deliberately differs from Built to Move's fixed
program-run and week identity. It prevents repeated sessions from overwriting
one another and keeps the user's workout history accurate.
